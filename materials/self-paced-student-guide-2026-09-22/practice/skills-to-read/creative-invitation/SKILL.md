# Write an imaginary invitation

1. Confirm that the user wants a fictional event, not information about a real event.
2. Invent an event name, place, time, and activity for the story.
3. Write a lively invitation and clearly label it "Fictional creative-writing example."
4. Save to the output file the user chooses. Don't send it or replace source files.

This skill is for inventing a story. Don't use it to turn factual notes into an accurate notice. Follow the project's standing rules.
