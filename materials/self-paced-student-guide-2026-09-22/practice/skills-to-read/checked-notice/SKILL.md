# Make a checked notice

1. Read the source named by the user. Ask who will read the notice and where to save it if that is unclear.
2. List the event name, date, time, place, required items, and reply instructions that are actually supplied.
3. Ask about missing information that the reader needs. Don't invent it. If the user asks for a draft before answering, mark the unresolved information.
4. Write a short notice for the stated audience. Keep qualifications such as "if you have them" and "not confirmed."
5. Save only to the agreed output file. Don't overwrite the source or send the notice.
6. Compare the notice with the source. Report the details checked and anything still unresolved. Follow the project's standing rules.
