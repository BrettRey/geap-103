# GEAP 103 Decision Log

Keep one continuing file here: `decision-logs/decision-log.md`.
If you already have a log, add to that file. Don't replace it with this template.

During practice, add short notes about useful learning and decisions. Give
each note a date and name the file you worked on. Write in your own words.

For entries you submit, use the assignment instructions in Blackboard and
the full course template. The existing requirement is about 150-200 words of
your own writing for each submitted entry, not counting copied AI excerpts
or the self-assessment sentence. Short practice notes help you prepare these
entries; they do not change the assignment requirements.
