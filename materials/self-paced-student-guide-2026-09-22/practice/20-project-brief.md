# Practice club event plan

This is a fictional classroom project. Don't contact anyone or buy anything.

We are planning a small student event. We need two parts:

1. A budget using every row of `03-snack-budget.csv`. Calculate the total.
   Explain what is included. These are practice prices, not current prices.
2. A list of questions to ask a room manager before an event. We need to know
   about the room, accessible entry, allowed activities, food, and booking.

The room, event date, booking rules, and any room fee are not known.
The questions must not pretend we already know the answers.

The two parts can be drafted separately. A final recommendation about whether
we can afford the event must wait until any extra costs are known.

Use separate output files: `budget-summary.md` and `room-questions.md`.
Don't edit this brief or the input data.
