# GEAP 103 Week 2: Shared Practice Repo Materials Package

**Title:** Getting AI to Do What I Mean — shared practice repo variant  
**Phase:** Discovery (Week 2 of 14)  
**Use with:** `lesson-plans/week-02-shared-practice-repo.md`  
**Public repo:** `https://github.com/BrettRey/geap-103-shared-practice`

This package standardizes Week 2 without replacing the original lesson. Everyone works from the same small files, so the class can compare outputs, prompt revisions, and verification moves more directly.

The same task set is also bundled inside `materials/geap-103-starter.zip` under `week-02/shared-practice/`, so students can work from the starter folder even if you do not want to send them to GitHub during class.

## Core teaching decision

Use the shared repo when you want:

- one public place students can find and download;
- common tasks that let you guide the room more easily;
- less account and AI-credit variance; and
- a clean no-live-AI fallback path.

Keep the original Week 2 lesson when you want the widest personal exploration from Week 1 wishes.

## Before class

- Open the public repo and test the download ZIP path.
- Download a local copy in case GitHub is slow.
- Decide whether every student will do Task 1 then Task 2, or whether Task 2 is for faster groups.
- Keep Task 4 ready as the fallback and comparison path.

## Slide sequence

### Slide 1: open the shared repo

> Open the Week 2 shared practice repo.  
> Download ZIP if needed.  
> Open `TASKS.md`.  
> Everyone starts with Task 1.

Teacher line:

> Today we are all starting from the same files. That will make comparison easier and reduce setup problems.

### Slide 2: the language cycle

| Say what you want | See what AI gives | Check the gap | Revise | Decide |
|---|---|---|---|---|
| prompt | generate | verification | revise | accept / modify / reject |

Teacher line:

> The cycle matters more than the tool. Today's files are small on purpose, so you can see the cycle clearly.

### Slide 3: task 1 summary challenge

> Read `practice-files/01-study-spaces-article.md`.  
> Ask AI for a short summary for a new B1 student.  
> Keep the opening times, food rule, and charger rule.

Prompt frame:

> Read this file. Write _____ for _____. Keep _____. End with _____.

### Slide 4: restatement check

> Before you generate, ask:  
> **"Tell me what you think I'm asking for."**

Teacher line:

> This shows you the gap before the tool spends effort writing the wrong thing.

### Slide 5: task 2 email challenge

> Read `practice-files/02-club-message-notes.txt`.  
> Turn the notes into a short email for classmates.  
> Keep the date, time, reply deadline, and one final question.

### Slide 6: compare two outputs

> Compare your partner's output with yours.  
> Or compare `prepared-outputs/04-output-a.md` and `04-output-b.md`.  
> Which one fits the task better? Why?

Sentence frames:

- "Output A meets the requirement about _____, but it misses _____."
- "Output B is stronger because _____."
- "A better prompt would say _____."

### Slide 7: Decision Log reminder

> Write about one task only.  
> What did you mean?  
> What did you say?  
> What did you get?  
> What did you verify?  
> What did you decide?

### Slide 8: Goal Document bridge

> Which shared task was easiest for you to explain clearly?  
> Which one connects to something you actually want to do?

### Slide 9: session review

> Speaking practice.  
> Describe one shared task: what the file asked for, what you expected, what AI gave you, and what you had to clarify.

## Instructor circulation prompts

| What you notice | What to say |
|---|---|
| Student prompted too vaguely | "What reader, format, or detail did you forget to name?" |
| AI omitted a required fact | "Show me where that fact is in the file. How will you tell AI to keep it?" |
| Student accepts output too quickly | "What will you verify before you keep it?" |
| Student is blocked on login or credits | "Move to Task 4. The goal is evaluation and revision, not account success." |
| Student finishes early | "Try Task 3 or improve Task 2 for a more specific audience." |

## Minimal teacher script

Use these lines often:

- "What did you actually ask for?"
- "What did the file say?"
- "What did the tool miss?"
- "What changed after you revised the prompt?"
- "How did you verify that?"

## Why this is a good fit for the current credit situation

- Students can complete meaningful Week 2 work with short, bounded chats.
- The no-credit fallback is already built into the same repo.
- The teacher can guide one common task instead of debugging twenty unrelated ones.
- Students still finish by connecting the shared task back to their own interests.
