Which word is it?

GEAP 103 · October 5

GitHub · Copilot (the harness) · model · agent · chat interface · session

  1. 1"I open it on my laptop, choose a project, and start a session."Copilot, the harness
  2. 2"Opus 5.5"A model
  3. 3"It read the club notes and saved club-message.md in my folder."An agent
  4. 4"I use it in my web browser. It only sees what I paste or upload."A chat interface
  5. 5"My portfolio repository is stored here, online."GitHub
  6. 6"One conversation with the agent, which I can reopen later."A session

Microsoft uses the name Copilot for many products. In this course, Copilot means the GitHub Copilot app.
