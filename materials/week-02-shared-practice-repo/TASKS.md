# GEAP 103 Shared Practice Tasks

You can use these files with **any** AI tool. You do **not** need Git, GitHub Education, or Copilot Student to begin.

## How to start

1. Open one practice file.
2. Read it before you ask AI anything.
3. Write or say a prompt.
4. Check whether AI kept the important details.
5. Revise your prompt if needed.
6. Save the result you want to write about in your Decision Log.

## Task 1: Make a useful summary

**File:** `practice-files/01-study-spaces-article.md`

**Your goal:** Ask AI to write a short summary for a **new B1 English student**.

**Keep these details:**

- the quiet zone opening times;
- the food rule; and
- the charger rule.

**End with:** one recommendation for a new student.

**Prompt frame:**  
`Read this file. Write _____ for _____. Keep _____. End with _____.`

**Verification question:**  
Did the output keep the opening times, the food rule, and the charger rule correctly?

## Task 2: Turn notes into an email

**File:** `practice-files/02-club-message-notes.txt`

**Your goal:** Ask AI to turn the notes into a short email for classmates.

**Keep these details:**

- the date;
- the meeting time;
- the reply deadline; and
- one final question.

**Prompt frame:**  
`Turn these notes into a friendly email for _____. Keep _____. End with _____.`

**Verification question:**  
Did the output keep every important detail from the notes?

## Task 3: Explain a small budget

**File:** `practice-files/03-snack-budget.csv`

**Your goal:** Ask AI to explain the table in **3 short sentences**.

**Include:**

- the biggest cost;
- the total cost; and
- one suggestion for reducing the budget.

**Prompt frame:**  
`Read this table. Explain it in _____. Include _____.`

**Verification question:**  
Is the total correct? Is the biggest cost correct?

## Task 4: No-live-AI comparison

Use these three files:

- `prepared-outputs/04-prompt.md`
- `prepared-outputs/04-output-a.md`
- `prepared-outputs/04-output-b.md`

**Your goal:** Decide which output fits the task better.

Write or say:

- which output is stronger;
- which requirement the weaker one missed; and
- what a better prompt should say.
