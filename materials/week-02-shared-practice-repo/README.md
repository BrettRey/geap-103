# GEAP 103 Shared Practice Repo Kit

This folder is the source kit for the public practice repository:

- **Public repo:** `https://github.com/BrettRey/geap-103-shared-practice`
- **Purpose:** give all students one easy-to-find, easy-to-download place to practise common Week 2 tasks
- **Starter kit copy:** also bundled inside `materials/geap-103-starter.zip` at `geap-103/week-02/shared-practice/`

The public repo is meant to be:

- easy to open in a browser;
- easy to download as a ZIP;
- usable with any available AI tool;
- usable without live AI through prepared outputs; and
- small enough that the whole class can work on the same files.

## What is in the kit

| Path | Purpose |
|---|---|
| `TASKS.md` | Student-facing task cards |
| `practice-files/01-study-spaces-article.md` | Summary task |
| `practice-files/02-club-message-notes.txt` | Email task |
| `practice-files/03-snack-budget.csv` | Table/data task |
| `prepared-outputs/04-prompt.md` | Comparison prompt |
| `prepared-outputs/04-output-a.md` | Weaker prepared response |
| `prepared-outputs/04-output-b.md` | Stronger prepared response |

## Suggested Week 2 use

1. Everyone starts with Task 1.
2. Most students continue to Task 2.
3. Faster students try Task 3.
4. Students without live AI or with limited credits use Task 4.

This preserves a common classroom experience while keeping a clear fallback path.
