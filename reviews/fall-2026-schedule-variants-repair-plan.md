### Combined Weeks 9–10 class
- At the end of Week 8, students choose an existing artifact to develop and write Goal Document entry 9 as a concrete task list. Students without dependable home technology do this before leaving class.
  
- Segment A compresses vocabulary and uses selectable demonstration stations rather than trying to demonstrate every project type.
  
- Segment B protects building time and the peer check-in. The peer check-in supplies sharing evidence.
  
- Segment C protects verification, process documentation, Goal Document entry 10, and the interest inventory for collaborative groups.
  
- The mid-semester Artifact Package receives an end-of-day or 48-hour deadline. A student who lacks home access receives an in-class submission path or campus-lab time; extra time must not presuppose a personal device.
  
- Group formation is finalized during the first 10–15 minutes of Week 11 so an absence during the combined class does not strand a student.

## GitHub and access repair
The documentation will distinguish five states that the current flow conflates:

1. A GitHub Free personal account can create repositories; it does not require GitHub Education approval.
  
2. GitHub Education verification is individually tailored and {--may--}{#s1} require{++s++}{#s2} a current dated document and an academic email.
  
3. Copilot Student activation is separate from Education approval and {--may--}{#s3} take{++s++}{#s4} {~~several days~>72 hours~~}{#s5}.
  
4. Local Git can demonstrate version control without GitHub or Copilot.
  
5. OneDrive/version-history or tracked-change equivalents can demonstrate the learning target when GitHub or installation is unavailable, if the student produces individual evidence that matches the rubric.
  

Changes:

- {--Delete “usually decided within minutes,” the fixed 72-hour promise, and the clean-account test. Use GitHub's current “individually tailored” and “may take several days” language.--}{#s6}
  
- Instructors test public links and downloads while signed out, and test their own authorized account/tool path. They do not attempt to reproduce a student's verification decision.
  
- Students report only a status category and exact on-screen wording. Instructors never receive identity or enrolment documents.
  
- Week 3 becomes a three-path activity: GitHub web, local Git, or version-history equivalent. A projector demonstration or a partner's repository is practice only and cannot count as an individual's evidence.
  
- Week 7 becomes a two-genre/two-tool activity: PR + comment exchange where available; otherwise tracked change/version-history handoff + response using the same “what/why/what not” language template.
  
- Remove the fallback that puts blocked students on branches of the instructor's repository. It still requires GitHub access, creates permission/roster work, and risks changes to a shared instructor-owned surface.
  
- Correct Week 3 materials: viewing an earlier commit is not a Restore episode. Students must actually recover an earlier version or use an equivalent recover operation.
  
## Non-happy-path controls by stage
| Stage | Trigger | Required branch |
| --- | --- | --- |
| Before Week 1 | No OneDrive, no personal device, late enrolment | Local Documents/campus computer path; portable catch-up packet; no OneDrive-only submission |
| Before Week 2 | No preferred AI or account quota exhausted | Any available AI or instructor-provided static mismatched outputs for evaluation; the student still writes the decision |
| Before Week 3 | No GitHub sign-in, Education pending, no install rights | Route immediately to GitHub Free, local Git, or version-history path; do not wait for Education/Copilot |
| Week 4 | Missing files/repository or absence | File System package may use local folder evidence; named make-up window; GitHub history is not required for the 7% package |
| Week 6 | File will not open or Copilot unavailable | Do not hold the whole class; provide accessible local/browser copies and calculator/manual or static-output evaluation paths |
| Week 7 | No fork, absent partner, account blocked | Equivalent handoff/comment exchange; re-pair without requiring instructor-repository access |
| Micro-Defence weeks | Absence, late arrival, or insufficient observation | Exact make-up date; F/P/D tracker; first-stop rule until every student has two full observations |
| Combined Weeks 9–10 | No draft, missing process notes, absent during group formation | Use an existing artifact; reconstruction template; finish group formation next meeting; access-neutral extension |
| Week 11 | DL curation incomplete or feedback late | Do not introduce new composition; retain eight-entry cap; protect feedback before final curation |
| Week 12 | Missing Git episode or partner unavailable | Staged individual recovery/error task and equivalent collaboration partner; do not turn reflection prep into Git support |
| Week 13 | Evidence not tagged, student freezes, class above 20 | Pre-class evidence check; fixed queue/timer; offline evidence list; scheduled make-up that does not erase another lesson |
| Async Week 14 | No home device, inaccessible media, no peer response | Complete before leaving Dec 14 or use a campus lab; allow audio, video, or text; do not grade production polish |
