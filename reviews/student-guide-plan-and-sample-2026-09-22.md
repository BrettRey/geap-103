# GEAP 103 student guide: format and sample task

## What I propose to make

A browser guide called **Work with AI**, with a downloadable practice pack. Students open the guide, choose their task, and start. HTML is the primary format: it supports direct file downloads, copyable requests, short help sections, and links to the next task. It will also have a print layout. The downloadable version will work without a website account; AI tools and GitHub still need their own access.

The opening screen will offer **Start here**, **Continue a task**, and **Work on my project**. The setup route will begin by asking what already works. Students won't repeat installation instructions when they can already open the app and use it.

I'll preserve the existing progression and task numbers. Each early task will have:

- **Your goal:** a small result the student can show.
- **You need:** the actual files, with downloads beside the instructions.
- **Do this:** short numbered actions, with one main action per step.
- **Check your work:** something the student can open, compare, or try.
- **Need help?** a concrete recovery action or a sentence for asking for help.
- **Try again:** a small variation with less language support.

Later tasks will gradually leave more choices to the student. Technical terms such as *commit* will stay where students need them, with a short explanation at first use. I won't replace the task with a long vocabulary lesson.

The sample below shows the proposed language and amount of support. It assumes that Tasks 1–2 have helped the student open a practice folder in the app and open Markdown files in an editor.

## Decisions the guide will preserve

Students don't have to finish all 27 tasks. The guide will show the common opening route, the point where students can begin a project, and optional work they can use when they need it. It will include a short “What you need to show” list covering the seven course outcomes. Recovering an earlier usable version and exchanging a change with a peer will remain explicit.

Students can change direction at any point. They don't need permission or a minimum number of attempts. The guide will explain that a late change leaves less time to produce a checked result and one visible improvement. It won't add new grading rules or make every task depend on teacher sign-off.

The agent's work log and the student's Decision Log will have different jobs. Students won't write a reflection after every button click. A short learning entry will point to work they can explain.

I'll supply the missing practice materials, including harmless safety examples, fictional profiles and forms, paired sources, an essay, short skills, and a small coding example with tests. Examples will be labelled as practice or fictional. Git exercises will use students' own practice copies, not require write access to the teaching repository or a partner's private portfolio.

The finished package will include the guide and practice files. I'll keep the teacher-facing progression as a separate reference. A private preview can support review; public posting is a separate step. Device-specific directions will need checking against the actual classroom setup, and I won't describe untested routes as tested.

## Sample student page begins here

# Task 3 · Make a message from notes

**Your goal:** Make a short message, save it as a file, and check the details.

**You need:** Your practice folder, the AI app, and the editor you used in Task 2.

These notes are for practice. This is not a real event. Don't send the message.

### 1. Read the notes

Open `02-club-message-notes.txt` in your practice folder.

Here are the notes:

> GEAP 103 volunteer team
>
> beach cleanup this Saturday, October 3  
> meet outside A building at 9:15 a.m.  
> bring water  
> bring gloves if you have them  
> we still need 4 more volunteers  
> please reply by Thursday at 12:00 noon  
> friendly tone  
> end with one question

Find the meeting time and the time to reply. They are different.

### 2. Ask AI to make the message

Open the AI session for your practice folder.

You can copy this request:

> Read `02-club-message-notes.txt`. Write a short, friendly email for the GEAP 103 volunteer team. Include all the event details. End with one question. Save it as `club-message.md` in the same folder. Don't change the notes or send the email.

Wait for the result. If the app asks for permission, read what it wants to do. If you don't understand, stop and ask for help.

### 3. Open the file

Find `club-message.md` in your practice folder. Open it in your editor.

You need the saved file, not only a message in the AI chat.

**Can't find it?** Ask:

> Where did you save `club-message.md`? Show me the folder and the file name. Don't make another copy yet.

### 4. Check the message yourself

Compare the file with the notes. Check each item:

- [ ] The event is on Saturday, October 3.
- [ ] The meeting is outside A building at 9:15 a.m.
- [ ] People should bring water, and gloves if they have them.
- [ ] The team needs four more volunteers.
- [ ] People should reply by Thursday at noon.
- [ ] The message is friendly and ends with one question.
- [ ] AI hasn't added information that isn't in the notes.

If something is wrong, explain the problem. You can use:

> The message says ____. The notes say ____. Please correct `club-message.md`. Keep the other details.

Open the changed file and check it again. If everything was correct, you don't need to invent a problem.

### 5. Save a short work record

Ask AI:

> Add a short entry with today's date to `work-log.md`. If the file doesn't exist, create it. Say which file you made, which checks you did, and what still needs checking. Don't say a check passed if you didn't do it.

Read the entry. Tell AI to correct anything that doesn't match what happened. Your checks and AI's checks may be different.

In your Decision Log, write a short entry about something you learned or decided. Name the file. These sentence starters can help:

> I can now ____.  
> In `club-message.md`, I checked ____.  
> I changed ____ because ____. / Next time, I need help with ____.

Use the lines that fit your work. Be ready to explain them in your own words.

### 6. Try again with less help

Use the same notes to make a short notice for a class noticeboard. Save it as `club-notice.md`.

Write your own request this time. Tell AI:

- which notes to read;
- who will read the notice;
- which details to include;
- where to save the file.

Open the notice and check it against the notes.

**You can move on when:** You can find both files and show how you checked their details. Next, Task 4 will help you change a file and bring back an earlier version.
