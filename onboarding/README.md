# GEAP 103 setup and support

This section helps instructors and students prepare for the GitHub, Git, VS Code, and Copilot parts of GEAP 103.

Start early. GitHub Education verification requires each student's own current documentation, and Copilot activation is a separate account process. Plan to begin as soon as the roster is available. After approval, allow **72 hours** for Copilot Student activation.

## Choose the right guide

- **Students:** [GitHub Education and VS Code: student setup](student-setup.md)
- **Instructors:** [Teacher onboarding and support plan](../admin/github-education-and-vscode-onboarding.md)

## What students need

For the full recommended setup, students need:

1. A personal GitHub account.
2. A way to prove current student status, such as a current student card, class schedule, transcript, or enrolment letter.
3. Git installed on the computer they will use.
4. Visual Studio Code installed.
5. GitHub Education approval and then Copilot Student activation, if they want the student benefit.

Students should use the same GitHub account throughout the process. They should never send a password, two-factor authentication code, or identity document to an instructor or classmate.

## Important distinction

GitHub Education approval and Copilot activation are separate. The important sequence is:

1. Apply for GitHub Education.
2. Wait for the Education approval.
3. After approval, wait 72 hours for the Copilot email.
4. Follow the email's instructions and check that Copilot Student is active.

A student may be approved for GitHub Education but still see Copilot Free during the 72-hour wait. They should not enter payment details while the included student benefit is being applied.

GitHub Free repositories do not require Education approval. The course is tool-agnostic: Education, Copilot, installation, or device delays must not prevent participation or graded evidence. Use the GitHub-web, local-Git, or version-history path in the student guide and teacher support plan.
